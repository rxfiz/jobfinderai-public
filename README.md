# JobFinderAI

JobFinderAI helps people discover job opportunities, compare role requirements with recorded experience, prepare reviewable CVs and cover letters, and organise applications. This public landing page uses synthetic product examples.

## Build locally

Requires Node.js 24.16.0 and npm.

```sh
npm ci
npm run build
```

The build creates the static website in `dist/`. Serve that directory with any static web host.
